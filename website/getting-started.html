Getting Started

Install SolGate, start the self-hosted API and embed the allowlist experience in your own site.

1. Clone and build

git clone https://github.com/Solgate-code/solgate.git
cd solgate
pnpm install
pnpm build

2. Start the API

cd packages/server
cp .env.example .env
# Configure SESSION_SECRET, ADMIN_API_KEY,
# SOLANA_RPC_URL and any OAuth credentials you need.
pnpm dev

The development API runs at http://localhost:8787 by default.

3. Start the admin interface

cd ../admin
pnpm dev

Use the admin interface to configure campaigns, requirements, allocation rules, exports and snapshots.

4. Embed with React

npm install @solgate/react
import { AllowlistWidget } from "@solgate/react";
import "@solgate/react/styles.css";

<AllowlistWidget
  baseUrl="https://api.myproject.xyz"
  campaignId="genesis-mint"
  theme="dark"
/>

5. Or embed without React

<div
  data-allowlist
  data-base-url="https://api.myproject.xyz"
  data-campaign="genesis-mint">
</div>

<script
  src="https://unpkg.com/@solgate/embed/dist/embed.global.js"
  defer>
</script>

Campaign model

Campaigns are defined as JSON. Requirements can include wallet signatures, token or NFT ownership, social verification, quizzes, captchas and custom modules. Required checks must pass before the entry becomes eligible.

{
  "id": "genesis-mint",
  "name": "Genesis Mint",
  "type": "nft-mint",
  "requirements": [
    { "key": "wallet", "module": "wallet-signature", "config": {} },
    { "key": "telegram", "module": "telegram-verify", "config": {} },
    { "key": "quiz", "module": "quiz", "config": { "passScore": 1 } }
  ],
  "allocation": {
    "mode": "tiered",
    "maxPerWallet": 1
  }
}

Production checklist

Use a production database, strong secrets, restricted OAuth return origins, HTTPS, rate limiting, a reliable Solana RPC endpoint, and snapshot your eligible set before mint. Review the repository security documentation before launch.
