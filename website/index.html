What SolGate provides

A modular SDK and self-hosted API for campaign verification and allocation.

Wallet & on-chain verification

Solana wallet message signatures, SPL and Token-2022 balance checks, NFT ownership checks and snapshot-based eligibility.

Social & custom requirements

X, Telegram, Discord, YouTube, custom quizzes and an extension API for project-specific verification modules.

Exports & mint integration

CSV, JSON, wallet lists, Merkle roots and proofs, eligibility APIs and signed webhooks for downstream mint or CRM systems.

Designed for projects that want control

No launchpad lock-in

Keep the user journey on your own website and integrate with your own mint stack.

Self-hosted data

Run the backend and database yourself. Export your own eligibility data whenever required.

Modular architecture

Use only the modules you need and extend SolGate for custom project requirements.

Alpha software. SolGate has automated tests and security hardening, but has not yet undergone a third-party security audit or production mint deployment. Review the security documentation before using it for high-value or production flows.
