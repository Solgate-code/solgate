# SolGate naming

The project name is **SolGate**.

Public npm packages use the `@solgate` scope:

- `@solgate/core`
- `@solgate/server`
- `@solgate/react`
- `@solgate/embed`

The repository is `Solgate-code/solgate`.

Use “SolGate” in user-facing documentation, README headings, SDK references and examples. “Solana allowlist” may be used descriptively, but it is not the product name.
