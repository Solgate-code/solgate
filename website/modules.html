SolGate Modules

Build the verification flow your project needs.

SolGate modules can be combined to create allowlists, token-gated experiences, NFT eligibility checks, community campaigns and other Solana access workflows.

Core

Solana Wallet Signature

Verify that the participant controls the Solana wallet connected to your application.

Off-chain signature No SOL payment

Necessary steps

  1. Add Solana wallet connection to your frontend.
  2. Request a server-generated nonce from SolGate.
  3. Ask the wallet to sign the verification message.
  4. Send the signature to the SolGate backend.
  5. SolGate verifies the Ed25519 signature and wallet ownership.

Environment 

SESSION_SECRET=replace_with_a_long_random_secret
SOLANA_RPC_URL=https://your-solana-rpc.example

Campaign requirement 

{
  "key": "wallet",
  "module": "wallet-signature",
  "config": {}
}
Social

X Verification

Connect an X account and apply campaign eligibility rules based on verified account data.

OAuth X Developer App

Necessary steps

  1. Create an X Developer account.
  2. Create an application in the X Developer Portal.
  3. Enable OAuth for the application.
  4. Add your SolGate callback URL.
  5. Copy the X client ID and client secret.
  6. Add them to the SolGate server environment.
  7. Ensure your X API access level supports the data required by your campaign.

Environment 

X_CLIENT_ID=your_x_client_id
X_CLIENT_SECRET=your_x_client_secret
X_REDIRECT_URI=https://api.example.com/oauth/x/callback

Campaign requirement 

{
  "key": "x",
  "module": "x-verify",
  "config": {
    "minAccountAgeDays": 30
  }
}

Telegram Verification

Verify Telegram identity and use Telegram participation as part of an eligibility campaign.

Telegram Bot Login verification

Necessary steps

  1. Open Telegram and contact BotFather.
  2. Create a bot for your project.
  3. Copy the bot token.
  4. Configure the Telegram login flow for your website.
  5. Add the bot to your community if membership verification is required.
  6. Store the bot token only on the server.

Environment 

TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_BOT_NAME=your_bot_name

Campaign requirement 

{
  "key": "telegram",
  "module": "telegram-verify",
  "config": {}
}
On-chain

SPL Token Ownership

Require participants to hold a specific Solana token or minimum token balance.

SPL Token Token-2022

Necessary steps

  1. Obtain the token mint address.
  2. Configure a Solana RPC provider.
  3. Define the minimum balance required.
  4. Add the token requirement to your campaign.

Environment 

SOLANA_RPC_URL=https://your-solana-rpc.example

Example requirement 

{
  "key": "token-holder",
  "module": "token-hold",
  "config": {
    "mint": "YOUR_TOKEN_MINT_ADDRESS",
    "minAmount": "1000000"
  }
}

YouTube Verification

Add YouTube-related campaign requirements to your eligibility flow.

Google API Social task

Necessary steps

  1. Create a Google Cloud project.
  2. Enable the appropriate YouTube API.
  3. Configure OAuth credentials if required.
  4. Add your callback URL.
  5. Add the required API credentials to your SolGate server.
Google and YouTube API permissions vary depending on the action being verified. Confirm that your chosen verification flow is supported by Google's current API policies.

Integration

Export & Mint Integration

Export eligible participants and connect SolGate to your mint infrastructure or backend systems.

CSV JSON Merkle Webhooks

Necessary steps

  1. Complete your campaign eligibility checks.
  2. Freeze or snapshot the final eligible set when appropriate.
  3. Export wallet addresses as CSV or JSON.
  4. Generate Merkle data if your mint system requires it.
  5. Use signed webhooks or APIs to integrate downstream systems.

Example webhook configuration 

{
  "url": "https://your-project.example/api/solgate",
  "events": [
    "entry.eligible"
  ]
}
Important: External APIs such as X, Telegram, Discord and Google may change their access tiers, OAuth requirements or permitted verification actions. Always confirm the current provider documentation before launching a production campaign.
